# Guía del proyecto Mi Portafolio

Esta guía explica cómo obtener, revisar y utilizar mi portafolio web. Está dirigida a compañeros que desean conocer el proyecto y ejecutarlo en su computadora.

## 1. Descripción del proyecto

Mi Portafolio es un repositorio personal donde presento información sobre mi perfil, las tecnologías que estoy aprendiendo y algunos trabajos realizados durante mi formación en desarrollo de software.

### Objetivo

El objetivo es organizar mis proyectos y mostrar mis conocimientos de manera clara, para que otras personas puedan revisar mi trabajo.

## 2. Requisitos

Antes de comenzar, se recomienda tener:

- Git instalado.
- Visual Studio Code u otro editor de código.
- Un navegador web actualizado.
- Acceso a internet para clonar el repositorio.

## 3. Instalación y uso

Sigue estos pasos para obtener el proyecto:

1. Abre una terminal en la carpeta donde deseas guardar el proyecto.
2. Clona el repositorio con el comando `git clone`.
3. Ingresa a la carpeta descargada.
4. Abre los archivos con Visual Studio Code.
5. Abre `index.html` en el navegador, si el proyecto utiliza esa estructura.

```bash
git clone https://github.com/MarkArellano1997/mi-portafolio.git
cd mi-portafolio
```

## 4. Archivos y comandos principales

| Elemento | Descripción |
|---|---|
| `README.md` | Presenta el repositorio y sus contenidos. |
| `docs/GUIA.md` | Contiene esta guía de instalación y uso. |
| `git clone` | Descarga una copia del repositorio. |
| `git status` | Muestra el estado de los archivos modificados. |
